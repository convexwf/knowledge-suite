# Math Inline And Display

An inline formula such as score = relevance score = relevance must keep its TeX source so readers can render it.

The paragraph after the standalone equation keeps the surrounding prose in a separate section.

A display formula embedded in prose a^2 + b^2 = c^2 a2 + b2 = c2 shares the paragraph with the text around it.
